# 王阳明 · 开导与抉择

依据王阳明原典，用现代汉语陪人辨清生活烦恼、责任与选择。回答像一位长期研读阳明的长者：先接具体困惑，一次讲透一个关键区别，再给一个优先可做的行动。

## 直接使用

普通聊天：把[完整指南.txt](prompts/完整指南.txt)附入这一次对话，再发送[启动提示词](prompts/启动提示词.txt)和你的事。也可全文粘贴[直接开始.txt](prompts/直接开始.txt)。v4完整入口约9.4万字符，已包含全部主题与原典，不必另传八本书；平台须确实读到所需材料，存入云盘不会自动加载。

支持文件夹 Skill 的平台：使用完整目录，以[SKILL.md](SKILL.md)为入口。它按问题读相关主题与完整原段，避免每次重读全库。豆包具体账号的导入、附件读取和效果尚未实机验证。[使用说明](docs/usage.md) · [平台状态](docs/platform-support.md)

## v4 补深了什么

- **八个主题：**思想全体、心即理与诚意格物、知行与求知、情绪与动静、立志与教学、关系与共同责任、教法语气、历史与书证。
- **52个去重原典单元，24,166字符原文。**在旧18个基础上新增34个，包括卷中书信的完整编号分段，以及《大学问》全篇六问。不是52本书，也不等于全集。
- **每个单元带解释条件。**保留原问、完整回答、能分清什么、怎样影响判断、何时反用或停用、上传材料定位及异文。
- **从原文提炼语气。**追问词义、先承认可取之处、分条件改答、承认未知、调整教法；也保留历史中的严厉，不塑造永远温柔且全知的圣人。

正文古人部分标“白话转述”，现代案例与建议另说，古文和出处集中篇末。保留实际资源与安全条件，不把所有困难归因于心态。此前[20题编辑示范](examples/20-life-questions.md)仍可参考形式，但不作为v4新能力的测试证据。

## 修改与构建

修改 `SKILL.md`、`references/topics/` 或 `references/library.json` 后，执行 `python scripts/build.py`，再执行 `python scripts/validate.py`。脚本只用Python标准库。来源原文有校改须写明版本依据；不能改掉旧试答来制造通过记录。真实个人记录和原始现代图书不加入公开仓库。
