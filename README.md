# 王阳明 · 开导与抉择

把王阳明的原典问答带进今天的生活困境，用现代白话，像一位熟读阳明的长者，陪人辨明事情、责任与选择。

## 拿来就用

1. 打开[直接开始.txt](prompts/直接开始.txt)，复制全文到豆包或常用 AI 的新聊天。
2. 接着讲自己的事，例如：“我答应的事没做到，一直自责。帮我看清接下来怎么办。”
3. 如果超过平台粘贴长度，附上同一个文件，再说“请按这份文件与我交谈”。需要平台确实能读取附件。

不用重新上传八本书。这份入口约1.9万字符，已包含核心规则、口吻示范与18则完整原典单元。只上传到云盘存放，不代表新聊天自动读到。

支持文件夹 Skill 的平台，使用完整目录，入口为[SKILL.md](SKILL.md)；它要求先实际读取随包的运行原典。想带上更多解释，可用[完整指南](prompts/完整指南.md)。具体账号的安装方式仍依平台现有功能，[平台验证状态](docs/platform-support.md)已区分已查证和未实测项。

## v3.1 改了什么

完整首答通常400–650汉字，开头回应具体困惑，一篇讲清一处分辨，突出一个优先行动。古人部分使用标明的“白话转述”，保留原问、原答与必要条件；只有劝告时用叙述，不编问答。现代案例和建议接在其后，古文及出处集中篇末。各题保留现实限制，不用同一套开头、段数和安慰句。

先看[20道人生困境的白话修订稿](examples/20-life-questions.md)，再决定这种说法是否适合你。

三个入口使用同一套核心要求和[18则完整运行原典](references/runtime-sources.md)。另有[12则深入分析](references/primary-dialogues.md)与[3组原创示范](references/long-dialogues.md)，可核对原文、现代解释和换方条件。

答案仍由大模型生成。本项目没有重新训练权重，不把“读过八本书”等同于每轮使用了八本全文。哪些资料真正进入方法、哪些只用于辨别来源，见[材料使用审查](docs/material-use.md)。

[版本验证与历史试答](docs/evaluation.md) · [阅读记录说明](docs/reading.md) · [版本记录](CHANGELOG.md) · [来源与授权](docs/credits.md)

这是依据文献的现代应用，现代话语不是王阳明原话。希望帮助人看清并减轻困扰，不保证每个人都会豁然开朗；豆包等具体账号的安装和效果尚未逐一实测。

## 继续修改

核心改动写入 `SKILL.md`，来源写入 `references/source-cards.json`。用 Python 3 运行 `python scripts/build.py` 更新运行原典、复制入口和完整指南，再运行 `python scripts/validate.py` 检查。脚本仅用标准库。

3.1版已新增[3组、6次实际试答](docs/final-dialogues.md)，逐轮检查条件改变后的判断；本地检查还验证入口一致性、来源与历史输入。20篇和多轮示范均经过编辑，不计作实际运行测试。此前11次v3答复仍属于3.0.0/3.0.1。具体效果与平台实测边界见[验证说明](docs/evaluation.md)。
