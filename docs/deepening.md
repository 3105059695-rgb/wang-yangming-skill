这次不是重新宣称逐页读完八本书。沿用381块阅读记录，重新读相关综合笔记，再回到提取文本核查新选原段及关键条件；《大学问》的全文及记录者说明另作完整复读。公版全文用固定公开版本分发，上传书的现代译注不复制入库。

## 增加的是哪些判断联系

| 主题 | 新增的关键关系 | 要防止的误用 |
|---|---|---|
| 思想全体 | 明德须在亲民实现；定静安后仍须详审；格致诚正是同一事的条理 | 只修心不顾人事，或机械拆成五步心内仪式 |
| 心即理与诚意 | 善意需要实际体现，做法还须讲求 | 真诚等于正确、自己感觉就是良知 |
| 知行与求知 | 问、思、辨也属实践；本体明不等于什么都知道 | 学不会就判没立志；查资料也被说成逃避 |
| 情绪与动静 | 七情有其作用，静坐是可调整的方法 | 情绪清零、再造一颗监督自己的心 |
| 立志与教学 | 方向稳定、分量渐进、教法随反馈改变 | 过量坚持、让学生为教法失效负责 |
| 关系与共同责任 | 一体关怀与不同才能分工并存；关系自有轻重 | 帮助别人必须包办一切，或私心之名否定生计 |
| 语气 | 由实际答问提炼12条规则，含宽劝、反诘、承认知识限度 | 仿古口头禅、虚构长者姿态、假装看透人 |
| 历史与书证 | 学说形成、教法变化、编录层次与文学加工 | 把小说对白当原话、将晚年话投到所有阶段 |

## 来源如何核对

八本各自的贡献、实际核读定位与限制见[逐书说明](book-contributions-v4.md)。

每个单元记录完整原文、固定版本、上传书定位和核对备注。新增的 B02、B07、B08 原文定位已回到提取文本检查；传记用于历史阶段、书证差异与教法线索。B01/B04/B05/B06中明确属于文学加工的内容仍不能成为古人逐字对话。

《大学问》为另外补充的公开原典，明确标注，不冒称来自用户PDF。保留公开转录与上传本的疑字差异：例如上10“道心为生”与上传两本“道心为主”，下201颜子句上传本漏“不”。公开底本原段没有暗改，解释指出校读依据；不能称完成所有影印逐字校勘。

原典间有张力也保留：例如“无知无不知”与“不知能问”的关系给出跨段解释，不装作原文毫无差别；严格省察与“勿另起一念照管”的适用条件分开，不为了现代舒适度抹掉古人的严厉。

## 尚不能声称完成的事

这仍是面向生活开导的选编研究，不是全集注疏。军政公牍、诗文、全部交游书信、阳明后学分歧没有全部建成运行资料；历史阶段的许多细节依上传传记引文，尚未逐一追到最早版本。权利、安全、现代专业支持是项目明确的应用选择，不假称王阳明已有现代立场。

增加原段与通过几组新试答，也不能证明思想蒸馏已经充分，更不能替代真实读者对语气和帮助程度的反馈。v3.1六次试答仍只证明旧版表现；v4的新对话、采用材料与问题另存[v4试答](v4-dialogues.md)。
