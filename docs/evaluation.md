# 3.1版修订与验证说明

日期：2026-09-14。当前版本3.1.0。

按最新写作要求重写20篇首答，同步核心示范、口吻规则、多轮示范、复制入口和完整指南。开头回应具体困惑；正文标明白话转述，保留原问原答与必要条件，只有劝告时不编对话；现代应用在转述之后，古文与出处在篇末。一篇突出一个优先行动，保留现实限制。

20篇为编辑后的写作示范，已由主助手对照对应完整原典直接复查。43段文末短引逐段验证为来源卡原文中的连续文字；格式、入口生成一致性、文件链接和历史输入绑定另由脚本检查。正文约419–533汉字（含题目，不含出处）。这属于文本与构建检查，不证明模型在新对话中一定遵守规则。

## 发布前新增实测：3组、6次实际回复

在本版规则保持不变的情况下，用三个新上下文执行对话：两组读取完整复制入口，一组读取 SKILL.md、运行原典和判断说明。每组先答第一轮，再给第二轮新事实；执行者不看未来转折、历史答复或评估报告。核心自带示范属于受测输入，不能称为完全未见相关示范。使用当前默认协作模型，未提供可复现的精确模型快照编号。

# 3.0系列历史审查：资料、解题与口吻

日期：2026-09-14。当时交付版本3.0.1。本轮实际审查了核心规则、思想与判断方法、语气、多轮示范、个人记录要求、来源及各平台入口，修改后重新构建。实际生成共4组、11次回复：初稿3组9次，修订后针对性复试1组2次。

结论：旧版存在“资料做过研究，但直接入口没有原典；认可的口吻仍在试稿”的脱节。v3把这两处接上了。实际对话能体现原典中的关键分别，也能随现实条件改变建议；同时发现了引文用字和剩余数量的错误。后者促成3.0.1的补强，不隐藏原答，也不把本次测试说成已证明对所有人有效。

|---|---|---|

## 实际试答，不用示范替代

前三组使用3.0.0初稿，共9次回复：两组读取完整复制入口，一组实际读取 SKILL.md、运行原典和辨事与抉择。每组从不带制作历史的新上下文开始，逐轮接收用户输入，不预先看未来转折、历史答案或审查标准。入口自带口吻示范，这是发布输入的一部分。生成文本没有润色。

[可直接阅读的全部试答](actual-dialogues.md)保留每轮输入和答复；原始JSON记录输入文件摘要。主助手检查，不是独立盲评。使用当前默认协作模型，工具未给出可精确复现的模型快照编号。

## 发现的错误和实际修改

设计组首答引作“行是知的工夫”，而当前运行原文为“行是知的功夫”。二者意思接近，但它没有注明异文，不能算按当前版本逐字引用。首答还在第一件有初稿后说“剩余三件”，应为另外两件，加上第一件尚需修改的部分。第二轮经用户指出后，模型明确纠正了数量和对项目完成程度的理解。

3.0.1补上两项要求：从本次已读原文逐字取引文，不凭熟悉的说法换字；使用数量前区分总量、已完成、待完成和修改部分并复核。初稿输入另存为[复制入口原稿](../evals/legacy/v3-initial-prompt.txt)及[文件夹核心原稿](../evals/legacy/v3-initial-SKILL.txt)，让这9次答复仍能与实际受测文本对应。

最后另开新上下文，用正式3.0.1复制入口做插画转行情境复试，共2轮，实际输出见[复试记录](../evals/transcripts/v3-recheck.json)。首答正确区分已完成1件、剩余2件，共需32小时；按8周计算可用32小时，进一步指出没有修改缓冲。存款可支撑6个月、停薪2个月后剩约4个月必要开销的计算正确。所用两处短引均能在当前原文中逐字找到，见[实际短引核对](../evals/quote-checks.json)。

第二轮追问依据时，模型准确定位S01及B08 p51–54、B07 p77–78与82–83，并说明：“我这次实际读取的是提示文件所附原典，没有另行打开这些PDF核验。”它把原典带来的“空谈与盲动均须纠偏”与现代计算、求职建议分开。这支持本次材料使用可追溯，不能扩大为每次都会可靠说明依据。

## 怎么理解“有王阳明的思维方式”

可观察的是：有没有采用原问里的分别，是否保留反向情形，能否用事实检验与更改判断。比如知行问答不是只催人做，哀哭问答不是要求人没有悲伤。核对这几处，比统计答了多少“良知、心即理”更有意义。

现代措辞、现金计算、沟通文本、排班安排仍是大模型在今天情境下生成的应用，不是书中已有的人生答案。一次答复引用了正确原文，也不能证明它的每一步内部生成都源自书本；模型自己的依据摘要只是可核查的说明。

## 仍未证明的部分

- 口吻已符合这次采用的结构要求，但有些句子仍有讲解感。没有让多位读者独立辨认人物相似度，不能宣称“与王阳明本人一样”。
- 没有真实使用者的长期反馈，无法证明能使人不痛苦或稳定产生顿悟。
- 本轮没有新增普通角色对照。旧v2的同题对照也能作合理判断，不能据此宣称技能的解题能力已经超过通用模型。
- 3.0.1只对新发现的引用与数量问题作针对性复试，没有把全部旧情境再跑一遍，也没有重新测试个人记录读写。记忆规则保留，v2的实际文件写入记录只作历史证据。
- 文件夹读取、完整附件静态构建与豆包账号实际安装是不同事情。尚未验证豆包云电脑导入、自动加载和跨次保存，详见[平台状态](platform-support.md)。
