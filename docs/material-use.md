# 资料到底怎样进入回答

答案仍由大模型生成。这份 Skill 做的是把原典、判断要求、口吻示范和边界交给模型，在当前上下文中约束它的回答；没有重新训练模型权重，也没有把八本书变成一个真人意识。

本次审查确认：有逐段阅读记录和实质分析，但 v2 的复制入口只带概括规则，原典另外存放且按需读取。因而“制作时读过”不能推出“回答时一定用了”。v3 把18则完整原典单元放进复制入口，文件夹入口也明确要求实际读取同一份运行原典。完整指南包含相同核心和原典，再附详细材料。

《大学问》是另补的公开原典，不算用户上传的第九本书。八本之间也有大量重复原典，并非八套独立的阳明思想。

## 从读书到一次回答，分四层看

1. **阅读覆盖：**381块都有记录。它证明可核对的覆盖记录存在，不认证理解深度。八本详细数量及无法辨字的例外见[阅读说明](reading.md)。本轮是审查现有日志、分析和成品并核对关键原段，没有重新逐页读完八本。
2. **提炼成品：**[思想说明](../references/philosophy.md)和[来源索引](../references/source-map.md)给出方法及来源；传记与小说中不可靠的对白被排除。
3. **运行时材料：**[18则运行原典](../references/runtime-sources.md)含完整问答、处境、现代应用和换方条件。它与[结构化来源](../references/source-cards.json)对应，复制入口实际包含这些原文。八本全文和私有研究笔记不在运行包中。
4. **实际答复：**核对它用了哪句、是否理解前后语境、建议是否随事实改变。模型声称“我依据某段”只是可检查的依据摘要，不是模型内部生成过程的因果证明。

## 怎么辨别是否只是贴名言

可以在一轮后追问：“请简短列出这次实际用到的原文、原问处境，以及哪一处改变了你给我的建议；哪些是现代应用？”然后和运行原典比对。

例如，知行问答的后半段明确区分盲动与空想。回答遇到“我不会这个技能”仍一味催行动，就算引文无误，也没有用好这段材料。七情问答承认人心合有七情；如果回答把悲伤本身判成修养差，也属应用失败。

运行原典中的 E 编号是与旧来源索引的主题关联，有些不是同一条原文的逐字定位；核对引文应以各卡的完整原文、固定链接及上传书定位为准。现代转用不会被自动包装为原典已经说过。

v3 的实际试答和仍未证明的部分见[审查与试答记录](evaluation.md)。不把一次同模型试答当作所有平台都会稳定做到，更不把“回答像长者”当作已保证让真实的人不再痛苦。
