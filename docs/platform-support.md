# 平台支持与验证状态

最省事的入口是复制 [直接开始.txt](../prompts/直接开始.txt) 到新聊天，接着说你的困扰。它不依赖安装技能或跨对话记忆。下面区分本包提供的使用方式与已经验证的平台能力。

## 选适合自己的入口

| 使用场景 | 怎么接入 | 当前边界 |
|---|---|---|
| 豆包或其他 AI 普通聊天 | 粘贴“直接开始”全文 | v3.1约1.9万字符，包含18则原典；具体长度限制与模型表现以实际使用为准，过长可尝试附入同一文件。 |
| 能读附件的聊天 | 按需附入 [完整指南](../prompts/完整指南.md) 和自己的记录 | 附件上传不证明内容已被完整读取；读不到应如实说明，核心提示词仍可独立使用。 |
| 豆包云盘 | 存放指南和记录，需要时带入当次聊天 | 已核实官方存储与文件问答说明；存储不等于每次自动加载。 |
| 豆包云电脑、工作模式、“我的技能” | 先看账号当前可用功能；不能导入时用普通聊天入口 | 本包未在具体账号中验证其安装、导入格式、调用或云端共享行为。 |
| 支持文件夹 Skill 的平台 | 按该平台实际说明安装完整目录 | 标准目录材料已提供；不能由格式相符推断每个平台均已兼容或自动触发。 |

Agent Skills 官方规范以包含 `SKILL.md` 的目录为基本结构，并允许附带参考资料；这解释本包的组织方式，不是各客户端安装成功的证明。见 [Agent Skills 规范](https://agentskills.io/specification)。

## 豆包：当前官方能确认什么

核查日期：2026-09-14。

[云盘使用须知](https://www.doubao.com/legal/ai_space)目前可访问，说明文件/文件夹的存储管理，以及部分文件的“问问豆包”等使用方式。它没有证明本仓库能直接作为云电脑技能导入，也没有证明新聊天会自动读取所有已存文件。

[记忆功能 FAQ](https://www.doubao.com/legal/memory_faq)目前可访问，说明记忆来源、容量及管理规则。文件记录和内置记忆分别处理；本包以用户可保存、可迁移的文件为续谈主本，详见 [保存与接续](memory.md)。

过去用于核查工作任务的 `/legal/DoubaoAgentModeNotice` 本次未能打开，故不再用它保证当前存在某个技能入口，也不据此推断该功能已经取消。具体按钮、导入格式和云电脑行为，仍待当前官方说明及账号实际验证。

## 本地交付与运行效果分开看

- **本地材料：**提供可复制提示词、合并指南、标准 Skill 目录与个人记录模板；这说明材料可拿走使用。
- **运行试聊：**3.1版新增三个新上下文、六次实际答复，使用复制入口与文件夹入口；[原样试答](final-dialogues.md)与[验证说明](evaluation.md)分别保存输出和观察。此前3.0系列、v2记录保留为历史证据。20篇和多轮示范不计测试；这些也不等于豆包账号安装和调用成功。
- **具体平台账号：**尚未逐一完成豆包等平台的安装、实际调用、跨次续谈与记忆持久性验证，不声称“全平台已测试通过”。

项目不以示范对话或一次试聊证明能够消除痛苦。遇到读不到文件、理解错或没有帮助的情况，可以直接指出，换问法、减少内容，或回到你眼前的实际处境。
