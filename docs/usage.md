# 怎么用

## 第一次：复制后直接聊

打开 [直接开始.txt](../prompts/直接开始.txt)，全文复制到一个新聊天，再把你的事接在后面。同一条消息发出也可以。粘贴过长时，将同一个“直接开始.txt”附入聊天，再说“请按附件与我交谈”。这份文字约1.9万字符，包含核心要求、口吻示范和18则完整原典，不需要 AI 再打开仓库中的其他文件才能开始。

你可以这样接上：

> 我最近总怕让别人失望，什么都答应，结果越来越累。先陪我理一理。

说你愿意说的部分就够了。它应直接回应这件事；需要了解情况时，一次问少量真正影响判断的问题。没有必要先报“加载成功”、测试记忆或填个人资料。

## 先看看它怎样回答

[20道人生困境示范](../examples/20-life-questions.md)展示3.1版的形式：先回应具体困惑，再用明确标注的“白话转述”带入原典，讲清它帮助分辨什么，给一个优先行动。古文和出处统一在篇末。只有劝告的原材料不改成对话，现代建议不冒充古人原话。示范经过编辑，不是豆包账号的实际运行记录。

## 想深入：带上完整指南

将 [完整指南.md](../prompts/完整指南.md) 添加到**这一次**聊天，接着说：“请结合这份指南继续陪我谈。”其中合并了方法、语气、情境与依据，适合想深入讨论的人。

如果平台读不到附件，就继续使用“直接开始”的文字；若粘贴时出现长度限制，按当前平台可用的附件方式提供。AI 无法读取时应如实说明，不应该编造已读内容。

普通聊天无需把原书、整个仓库或 `references/` 里的文件逐个上传。

## 平时怎样聊

可以谈关系、工作、自责、失落，也可以请它比较几条路。你不必把烦恼先翻译成“知行合一”“致良知”之类的概念。

- 只想被听见：“现在先别给办法，陪我把这件事说清楚。”
- 想判断选择：“帮我比较留下、离开和再观察一段时间，各自需要什么条件。”
- 它理解错了：“我不是怕丢脸，我是真的没有精力。请按这个情况重新想。”
- 想核对依据：“请简短列出这次实际采用的原文、原问处境、对建议的具体影响，以及现代延伸。”
- 回答太满：“说短一点，先抓住最重要的一处。”

它应接受更正，允许你暂时拿不定主意。是否有帮助，要看你的真实感受和生活中的变化。

## 如果平台支持文件夹 Skill

按所用平台当前的安装说明，安装整个 `wang-yangming` 目录，保留根目录的 [SKILL.md](../SKILL.md)、`references/`、`prompts/` 与 `templates/`。不要只把一个附件上传成功，就当作已经安装了技能。

`SKILL.md` 包含对话规则和口吻示范，并要求首次完整开导前实际读取 `references/runtime-sources.md`；其他参考材料用于深入。不要只安装一个主文件而漏掉原典。安装后，在该平台实际支持的调用方式下使用；没有此类入口时，复制提示词就能开始，不必为聊天另配开发工具。

豆包的云盘、普通聊天、云电脑或自定义技能不能互相当作同一种入口。当前可确认的能力与未实测项见 [平台支持](platform-support.md)，这里不预写不存在的导入按钮或格式。

## 想下次继续

聊完再说：“请整理我确认过的重要背景、当前选择和实际进展，生成我的记录。”检查内容并保存。下次新聊天中，重新提供“直接开始”和最新版记录，直接说“我们接着这件事谈”。详见 [保存与接续](memory.md)。
