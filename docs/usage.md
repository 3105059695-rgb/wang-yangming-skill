# 怎么用

把[完整指南.txt](../prompts/完整指南.txt)添加到当前聊天，发送[启动提示词](../prompts/启动提示词.txt)，并把末尾占位文字换成自己的事。例如：“我总怕让别人失望，什么都答应，最近已经没有精力了。”

完整文件约9.4万字符，含核心规则、八个主题及52个原典单元。支持长文本的平台也可粘贴[直接开始](../prompts/直接开始.txt)全文，两者实质材料相同。不要只复制短启动提示词却省掉附件，那样模型没有本库原文。

平台读不到附件、只读摘要或截断时，不能声称完成读取。可先问：“请找到与此事有关的完整原段，再作答；找不到就直说。”这仍是可检查的声明，需要与指南实际文字对照，不能只信一声加载成功。豆包的具体限制与账户行为未实测。

它应直接回应困惑，不要求填写资料表、不先介绍体系。古人部分标白话转述，现代建议另说，短引与出处集中篇末。一次突出一个行动；若你只想谈悲伤，可以说“先陪我说，不急着给办法”。

若它理解错，直接给新的事实。例如：“我不是怕丢脸，我每天确实只有半小时。”它应随条件调整，不能继续重复同一个心理原因。想查依据，可问：“原问是什么？其中哪一个区别改变了建议？哪些属于现代应用？”

## 文件夹 Skill

安装完整目录，保留[SKILL.md](../SKILL.md)、`references/`、`prompts/`、`templates/`。入口先读思想全体，再按具体问题读取一至两个主题和所需原典文件。读过且仍在上下文中的资料不重复读取；新问题超出所读范围再补读。

这使日常回答无需每次重读八本书或52个单元。具体平台的安装入口依实际功能，不能把普通附件或云盘存储当作已经安装Skill。[平台状态](platform-support.md)
