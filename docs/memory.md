# 保存与接续

第一次可以什么都不记录，直接聊。等你想下次接着谈，再保存一份自己的记录。

## 聊完时整理

可以对 AI 说：

> 请把我确认过、对下次谈话仍有用的背景、选择和进展整理成“我的记录”。没有说过的不要补；你的推测不要当作事实。先给我检查。

也可以从 [我的记录模板](../templates/我的记录.md) 开始。不必填满，只留你愿意保留的内容：正在面对什么、有哪些现实限制、已经决定做什么、实际怎样了，以及什么开导有帮助或使你更有压力。

## 检查，然后保存

把不准确的改掉，不想留的删掉，写上日期和版本。另存到你掌握的位置，下次用最新版即可。真实姓名、详细地址等与继续交谈无关的信息不必记。

保存有三个不同状态：

| AI 实际完成了什么 | 可以怎样说 |
|---|---|
| 只在聊天里整理文字 | “已整理，你可以复制保存。” |
| 生成可下载文件 | “已生成文件，请下载到你要保留的位置。” |
| 真实写入指定文件，并重新读取核对成功 | “已保存”，同时说明文件位置和版本。 |

没有文件写入能力时，不能声称已更新你的云盘或长期记忆。只说“帮我记住”也不等于已保存了这份文件。

## 换对话、换平台

带上 [直接开始.txt](../prompts/直接开始.txt) 和最新版“我的记录”，直接继续说事情。AI 应根据本次实际可读的内容接续，不需要你先通过加载检查；旧记录读不到，就从你这次说的话谈起，也不假装记得。

**可编辑、可携带的“我的记录”是主本。**平台自身记忆可以补充，但不保证完整，也不代替你的文件。

豆包官方说明，内置记忆从聊天文本中提炼，上传文件等不属于其记忆来源，并有容量与更新限制；因此上传“我的记录”不等于它自动成为长期记忆。关闭记忆或删聊天也不等于删除已保存的记忆。见 [豆包记忆功能 FAQ](https://www.doubao.com/legal/memory_faq)。

想忘掉一件事，就从新记录中移除，并在使用的平台另行管理相关记忆或旧文件。AI 只能确认自己实际完成的删除范围。
