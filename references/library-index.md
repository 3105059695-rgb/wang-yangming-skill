# 资料入口：先辨问题，再读主题与原段

## 引用与判断的限度

原文采用固定公开转录，上传古文用于对读；它们不是影印校勘定本。遇疑字依版本说明，避免拿疑字作权威断语。每次古人部分标白话转述，现代做法另说，短引与出处放文末。若主题与原段不支持当前问题，承认这个缺口，不添造古人问答。
